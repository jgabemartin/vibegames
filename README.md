# vibegames
repo for vibe-coded games

## Games

- [platformer-game](platformer-game/): **Western NY Farm BMX Dash**, a browser platformer with three levels (Day, Sunset and Night), five weather zones, music and sound effects. See [its README](platformer-game/README.md) for controls and details.

## How to play

These games need no install and no internet connection.

1. Download [vibegames-main.zip](https://github.com/jgabemartin/vibegames/archive/refs/heads/main.zip). You can also click the green **Code** button on the repo page, then **Download ZIP**.
2. Unzip it.
3. Open the game's folder (for example, `platformer-game`) and double-click `index.html`. It opens in your browser.
